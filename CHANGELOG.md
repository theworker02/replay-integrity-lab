# Changelog

## 1.0.0 - 2026-10-21

First public, versioned research release. It packages the executed in-memory and controlled filesystem experiments, raw trial data, checksum manifests, regression tests, an expanded ten-page non-peer-reviewed preprint, citation metadata, and archival submission metadata. The empirical claims remain exploratory and bounded to the synthetic deterministic workloads described in the manuscript.

## 0.2.0 - 2026-10-21

Adds a 96-scenario controlled filesystem experiment with actual temporary file reads and writes, raw data and provenance manifest, four additional tests, a ten-page v0.2 manuscript, an explicit interpretation section, and a worked omitted-dependency trace. The controlled experiment confirms the pilot's qualitative result: sampled auditing reduces but does not eliminate stale reuse under incomplete dependency information, and can exceed full-replay task work.

## 0.1.0 - 2026-10-21

Initial deterministic synthetic benchmark, six regression tests, 480 pilot scenarios and 2,400 policy evaluations. Adds raw results, checksums, a six-page manuscript draft, and a prospective protocol written after pilot inspection. Creates a private GitHub research repository. No public preprint submission or DOI.
